# Script Consolidation Work Documents

**Archived:** 2025-12-23

**Reason:** Internal work documents from script consolidation project (November 2025)

## What These Are

These documents were created during a major script consolidation effort in November 2025 to analyze and refactor the OmniFocus script helper functions. They represent internal working documents, not reference documentation.

## Contents

| File | Purpose |
|------|---------|
| `call-graph.md` | Dependency analysis of helper functions |
| `consolidation-opportunities.md` | Identified consolidation targets |
| `conversion-templates.md` | Templates for script conversion |
| `dead-code.md` | Unused code identified for removal |
| `essential-bridge-design.md` | Bridge pattern design decisions |
| `flaky-integration-tests.md` | Test stability issues found |
| `helper-categorization.md` | Categorization of helper functions |
| `helper-inventory.md` | Complete inventory of helpers |
| `helper-pain-points.md` | Pain points identified during analysis |
| `helper-usage-analysis.md` | Usage patterns of helper functions |
| `phase2a-summary.md` | Phase 2A completion summary |

## Why Archived

These documents served their purpose during the consolidation effort. The actual outcomes are now reflected in:
- Production code in `src/omnifocus/scripts/shared/`
- Active documentation in `docs/dev/PATTERNS.md`
- Lessons learned in `docs/dev/LESSONS_LEARNED.md`

## When to Reference

You might find these useful if:
